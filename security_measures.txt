PHP Blog Project – Security Enhancements (Task 4)
-------------------------------------------------

1. 🔐 Prepared Statements:
   - Replaced all raw SQL queries with prepared statements using mysqli_prepare().
   - Prevented SQL Injection on login, registration, and all CRUD operations.

2. ✅ Input Validation:
   - Server-side validation added for all user input (empty fields, length checks).
   - HTML5 client-side validation (e.g., required, minlength) included on all forms.

3. 🔒 Password Handling:
   - Passwords hashed with password_hash() during registration.
   - Verified with password_verify() during login.

4. 🛡 Output Escaping:
   - All dynamic content (titles, content, usernames) escaped using htmlspecialchars().
   - Prevents XSS attacks when displaying user-generated content.

5. 🔐 Session Security:
   - Regenerated session ID on login using session_regenerate_id(true).
   - Session-based access checks added to all protected pages.

6. 👤 Role-based Permissions:
   - Added 'role' column to users table (`admin`, `editor`).
   - Only post creator or admin can edit/delete a post.
   - Editors can create posts and view all posts.

7. 🔒 General Best Practices:
   - Used POST method for forms that modify data.
   - Error messages kept generic to avoid information leakage.

-------------------------------------------------
These measures enhance both data integrity and application security.
